# データポリシー

## 禁止

- 架空企業、架空工場、ダミー値、例示レコード
- 二次記事だけを根拠にした確定値
- 工場と本社、法人と物理拠点の混同
- 推測した生産能力、面積、投資額
- 出典URL、取得日、根拠箇所の欠落

## 採用可能な出典

1. 企業公式サイト、法定開示、統合報告書、決算資料
2. 政府・規制当局・統計機関の公開データ
3. 国際機関が公式統計として配信するデータ
4. 公式工業団地・投資促進機関の登録情報

## 国別カバレッジ

- 国プロファイル: ISO 3166-1全249コードを常時保持
- 工場: 0件の国を可視化し、厳格リリースでは1件以上を必須化
- 「データなし」を0や推計値で埋めない
- 未収録と値0を明確に区別する
