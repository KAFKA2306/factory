# データポリシー

## 禁止

- 架空企業、架空工場、ダミー値、例示レコード
- 二次記事だけを根拠にした確定値
- 工場と本社、法人と物理拠点の混同
- 推測した生産能力、面積、投資額
- 出典URL、取得日、根拠箇所の欠落

## 採用可能な出典

1. 企業公式サイト、法定開示、統合報告書、決算資料
2. 政府・規制当局・統計機関の公開データ
3. 国際機関が公式統計として配信するデータ
4. 公式工業団地・投資促進機関の登録情報

## 訂正

誤りを見つけた場合は、推測でその場を埋めず、訂正根拠となる一次情報を確認して正準JSONLをPull Requestで更新します。変更時は既存citationを無言で消さず、なぜ旧値を置き換えるかを差分またはPR説明から追跡できるようにします。

複数の採用可能な一次情報が意味上矛盾し、どちらが現況を表すか確認できない場合は、一方を恣意的に採用しません。解消できるまで正常な確定値として追加・上書きせず、該当claimを未確認として扱います。公開API/MCPも欠損を0や推定値へ変換しません。

source URLが失効しても、別の一次情報で同じclaimを検証できるまでは「リンク切れだから値は正しい」とは扱いません。取得日、publisher、根拠箇所は訂正後も必須です。

## 国別カバレッジ

- 国プロファイル: ISO 3166-1全249コードを常時保持する
- 工場レコード収録国・地域: **179件を現行スコープの上限**とする
- 179件を超えるcoverage追加は通常更新では行わず、明示的なスコープ変更を必要とする
- 未収録国・地域は品質欠陥や自動バックログとして扱わない
- 「データなし」を0や推計値で埋めない
- 未収録と値0を明確に区別する
- 公式一次情報で該当工場がないと確認できる場合だけ `verified_no_qualifying_factory` を記録する
- coverage件数を増やす目的だけの弱い根拠、重複拠点、会社単位レコードの水増しを禁止する

今後の優先順位はcoverage拡張ではなく、既存レコードの一次情報の強度、物理拠点粒度、重複排除、製品・工程・設備・投資・財務データの品質向上とする。
